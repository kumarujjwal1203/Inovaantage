# Inovaantage - Geospatial, Utility & Telecom Software Engineering Studio

Inovaantage is a premier digital engineering firm architecting next-generation digital products, high-performance geospatial (GIS) systems, 5G telemetry platforms, and enterprise AI solutions.

## 🚀 Key Features & Capabilities

- **Signature Capabilities**: Interactive 3D particle morphing canvas representing GIS Utility Migration, 5G Telemetry, Cloud Solutions, and Custom Development.
- **Featured Case Studies**:
  - `rUNr® Migration Engine` — Automated GIS network schema converter.
  - `5G Fiber Stream` — Real-time geospatial telemetry dashboard.
  - `PostGIS Spatial Lake` — High-throughput geospatial query engine.
  - `Grid AI Telemetry` — Smart grid predictive failure monitor.
- **Interactive UI & Dark Aesthetics**: Built with Tailwind CSS, Framer Motion, and Three.js / React Three Fiber with glassmorphic styling (`#050507`).
- **Global Reach & Presence**: Interactive location map & directory across Singapore, Australia, India (Hyderabad), and UK.
- **Responsive Architecture**: Fully responsive across mobile, tablet, desktop, and ultra-wide viewports.

## 🛠 Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **3D Graphics & Animations**: Three.js, @react-three/fiber, Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM v6

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
